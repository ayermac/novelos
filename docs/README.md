# Novelos Documentation

This directory keeps project documentation for Novelos. The canonical product and engineering documentation lives under `docs/codex/`.

## Entry Points

- `codex/README.md` - current baseline, active version notes, key links, and local verification commands.
- `codex/planning/` - historical roadmap and pre-v6.6 implementation plans/specs.
- `codex/specs/` - current v6.6+ version specs.
- `codex/reports/` - completion reports and acceptance summaries.
- `codex/reviews/` - review notes, defects, and verification records.
- `codex/next/` - proposed next direction and unapproved future plans.
- `codex/release/` - release and desktop packaging procedures.

## Documentation Rules

1. Treat `docs/codex/README.md` as the first stop for current truth.
2. Put new version specs in `docs/codex/specs/` once the scope is approved.
3. Put exploratory or not-yet-approved plans in `docs/codex/next/`.
4. Keep completion facts in `docs/codex/reports/` and review findings in `docs/codex/reviews/`.
5. Do not commit local agent scratch plans under `docs/superpowers/`; use `docs/codex/next/` for project-relevant plans.
