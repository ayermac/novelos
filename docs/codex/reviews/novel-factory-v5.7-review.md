## 技术债务

### 1. 前端选区 API 限制

- **描述**: 当前使用原生 textarea selection API
- **影响**: 选区功能有限，不支持复杂文本操作
- **优先级**: 中
- **建议**: 在 v5.8 中考虑引入轻量级编辑器

### 2. 版本对比性能

- **描述**: 使用 Python `difflib` 处理大文本可能较慢
- **影响**: 超长章节（>10k 字）对比可能卡顿
- **优先级**: 低
- **建议**: 在 v5.7.x 中增加文本长度限制或异步处理

### 3. 缺少版本搜索

- **描述**: 版本列表只支持时间排序，无搜索功能
- **影响**: 版本多时查找不便
- **优先级**: 低
- **建议**: 在 v5.8 中增加版本搜索和过滤
