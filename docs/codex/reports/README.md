# Completion Reports

This directory records what was actually delivered and verified for completed work.

Reports should be factual:

- version or topic
- shipped changes
- verification commands and results
- known follow-up risks
- links to the matching spec and review when available

Do not put future requirements here. Future or proposed work belongs in `../next/` until approved, then in `../specs/`.
