## 0. 执行摘要

**核心结论：skill 子系统对 ChapterBrief 字段零数据依赖。**

对 27 个 skill 文件逐一扫描 23 个 ChapterBrief 字段的三种访问形式（quoted-key `"<field>"`、属性 `.<field>`、下标 `["<field>"]`/`['<field>']`），**全部 27 个文件对全部 23 个字段的引用计数均为 0**。

原 v6.10.18 计划 §8 "Skill 体系依赖审计" 所列的高风险担忧（`foreshadowing_debt_skill.py` 依赖 `ledger_debts_to_pay`、`fact_lock_skill.py` 依赖 `contract_checklist`、`chapter_seam_skill.py` 依赖 `scene_count_target` 等）**经核实均不成立**。skill 文件名与字段名的重叠是**概念同名**（都指向同一叙事概念），而非数据依赖--skills 读取的是运行时 payload（章节正文 + 上下文字段），不是 ChapterBrief 契约字段。

**影响**：v6.10.18 字段弃用**无需任何 skill 适配**。计划中"Skill 适配"工作量可整体移除，工期与风险双双下调。

## 1. 审计方法

对每个 skill 文件 `f`、每个字段 `field`，执行：

```bash
grep -En "\"$field\"|'$field'|\.${field}\b|\[\"${field}\"\]|\['${field}'\]" "$f"
```

覆盖：
- 字符串键：`"field"` / `'field'`（dict/JSON 访问）
- 属性访问：`.field`（Pydantic/model 属性）
- 下标访问：`["field"]` / `['field']`

字段集（23）：`chapter_goal`、`reader_payoff`、`protagonist_agency`、`forbidden_moves`、`core_loop_target`、`primary_payoff`、`payoff_evidence_plan`、`pressure_budget`、`payoff_budget`、`upgrade_or_skill_use`、`character_arc_moves`、`mystery_actions`、`conflict_actions`、`ledger_debts_to_pay`、`new_debts_allowed`、`scene_count_target`、`opening_hook`、`ending_hook`、`quality_threshold_overrides`、`supporting_mechanisms_used`、`new_mechanisms_allowed`、`drift_risks`、`contract_checklist`。

## 5. 结论与建议

### 5.1 结论
- skill 子系统与 ChapterBrief 契约字段**完全解耦**。
- v6.10.18 标记字段 deprecated、v6.10.19+ 移除字段，**对 skill 系统零影响**。

### 5.2 对 v6.10.18 计划的修订建议
1. **移除计划 §8 的 Skill 适配工作量**与 §9.2/§9.3 中"Skill 体系适配"任务项。
2. **移除风险表**中"Skill 体系失效"风险项（或降级为"极低"）。
3. 工期估算下调：阶段 0 的 skill 审计已完成（本报告），阶段 2 的"Skill 适配"任务删除，预计缩短工期。
4. 计划 §11 风险表中"前置审计缺失导致删除关键字段"的担忧，在 skill 维度**已消除**；剩余前置风险集中于两个 `ChapterBrief` 类归一化（见字段审计报告 §1.3）。

### 5.3 阶段 1 无需 skill 侧动作
阶段 1（风险评估 + 迁移方案设计）无需为 skill 子系统设计任何适配方案。迁移验证面可排除 skill 层。

## 6. 审计局限

- 本审计仅扫描静态文本引用。若 skill 通过**动态字段名**（如 `getattr(brief, some_var)`）访问字段，静态 grep 无法捕获。但通读 skill 入口签名（payload-based）后，动态访问的可能性极低。
- 未追踪 skill 注册表是否在元数据中声明字段依赖（`manifest.py`/`registry.py`）。建议阶段 1 复核 `manifest.py` 的 skill 元数据字段，确认无字段名硬编码。
