# v6.11.0 研究报告：原子工具原型

**研究分支**: `research/v6.11.0-genesis-split`
**创建日期**: 2026-07-13
**研究课题**: v6.11.0 架构优化研究 — 原子工具、统一异常、依赖注入

## 1. 研究课题概述

v6.11.0 是一个**独立于版本路线的技术研究课题**，按季度 OKR 管理。核心研究方向：

1. **原子工具原型** - 在 LangGraph 节点内实现"三件套"模式 ✅
2. **异常统一框架** - 统一 1,206 个 try/except 的异常类型 ✅（已存在）
3. **依赖注入容器** - AgentContainer 实现单例和懒加载 ✅
4. **状态视图原型** - ChapterProgressView 聚合 FactoryState 字段 ✅

---

## 2. 研究成果

### 2.1 原子工具原型（已完成）

**实现文件**: `novel_factory/workflow/nodes/base_tool.py`

**核心类**:
- `NodeToolResult` - 封装执行结果
- `BaseNodeTool` - 抽象基类，定义三件套接口
- `AuthorNodeTool` - 具体实现示例

**三件套模式**:
```
1. Load artifacts  → 加载上下文（从 DB/state）
2. Execute agent   → 执行核心逻辑（LLM 调用）
3. Save artifacts  → 持久化结果（写入 DB）
4. Update progress → 推进状态
```

**验证结果**: 导入测试通过，workflow 测试 95 passed

---

### 2.2 异常统一框架（已存在）

**实现文件**: `novel_factory/exceptions.py`（v6.10.20 已实现）

**4 层异常类型**:
```python
class AgentExecutionError(Exception):  # Agent 层
class DBTransactionError(Exception):   # DB 层  
class APIValidationError(Exception):   # API 层
class LLMProviderError(Exception):     # LLM 层
```

**使用情况**:
- `APIValidationError` 已在多个 API 路由中使用
- `AgentExecutionError` 已在 `agent_runtime/base.py` 中使用

---

### 2.3 依赖注入容器原型（已完成）

**实现文件**: `novel_factory/agents/container.py`

**核心类**: `AgentContainer`

**功能**:
- 单例模式（每个 agent 类型只创建一次）
- 懒加载（首次访问时创建）
- 可注入 mock（用于测试）
- 上下文管理器支持

**使用示例**:
```python
container = AgentContainer(repo, llm)
author = container.get_author()
editor = container.get_editor()
```

---

### 2.4 状态视图原型（已完成）

**实现文件**: `novel_factory/models/state_views.py`

**核心类**:
- `TokenUsage` - Token 使用量
- `QualityGateSummary` - 质检结果摘要
- `ChapterProgressView` - 章节进度视图
- `ProjectProgressView` - 项目进度视图

**使用示例**:
```python
state: FactoryState = get_workflow_state()
view = ChapterProgressView.from_state(state)
return view.model_dump()
```
