## 3. 实施细节

### 3.1 拆分策略

采用**渐进式拆分**策略：

1. **创建包目录** → 移动原文件为 `_endpoints.py`
2. **提取独立模块** → models, progress, utils, normalizer
3. **提取大型模块** → scaffold, coercer
4. **提取 LLM 模块** → llm.py（LLM 调用、提示构建、修复）
5. **更新导入路径** → 相对导入改为绝对导入
6. **导出公共 API** → `__init__.py` 重导出所有公共符号

### 3.2 遇到的问题与解决方案

| 问题 | 解决方案 |
|------|---------|
| 相对导入失效 | 改为绝对导入 `from novel_factory.api.deps import ...` |
| 测试访问内部变量 | 在 `__init__.py` 中重导出 |
| 函数重复定义 | 删除 `_endpoints.py` 中已迁移的函数 |
| 文件编辑残留 | 手动清理重复内容 |
| monkeypatch 目标错误 | 更新测试中的 patch 路径从 `genesis_routes._build_genesis_llm` 改为 `genesis_routes.llm._build_genesis_llm` |
