# Version Specs

This directory is the home for approved v6.6+ implementation specs.

## Naming

Use:

```text
novel-factory-vX.Y.Z-short-topic-spec.md
```

## Lifecycle

1. Draft exploratory plans in `../next/`.
2. Move or rewrite the approved scope here as a spec.
3. Implement against the spec.
4. Record completion facts in `../reports/`.
5. Record review findings in `../reviews/`.
