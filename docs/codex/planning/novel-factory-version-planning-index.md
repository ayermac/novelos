# Novel Factory Version Planning Index

Status: canonical documentation index.

This index maps shipped or reviewed versions to their planning/spec source, completion report, and review record. It closes the lookup gap where some shipped versions are covered by umbrella plans instead of one file per version.

## How To Read This Index

- **Standalone** means the version has a directly named planning/spec file.
- **Umbrella** means the version is planned as a section inside a broader version spec.
- **Retrospective** means the planning note was reconstructed from the accepted implementation and report because the original work was an acceptance/hotfix pass.

## Earlier Standalone Planning

For v1 through v6.1, use direct version-named files in this directory and `novel-factory-roadmap.md` as the historical route map. These older plans predate the `specs/` split and are intentionally left in place.

## Maintenance Rules

1. When a new version ships, add it here in the same commit as its spec/report.
2. If a subversion is covered by an umbrella spec, add an explicit row instead of creating empty duplicate specs.
3. If a shipped version has no prior plan because it was an acceptance/hotfix pass, add a retrospective planning note with scope, constraints, acceptance, and follow-up.
4. Do not rely on reports or reviews alone as planning sources.
