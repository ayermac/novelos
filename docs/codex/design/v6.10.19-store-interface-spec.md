# v6.10.19 Store 接口设计规格

> 版本: v6.10.19 Phase 1
> 状态: Draft
> 日期: 2026-07-08

## 0. 设计目标

在现有 32 个 Repository 之上增加 8 个聚合 Store 作为统一入口（Facade 模式），不做物理合并。Store 调用底层 Repository，提供聚合查询。

### 原则
- Store 是聚合层，不是替代层
- 底层 Repository 全部保留，不删除
- 双轨并存
- Store 只做查询聚合，不做写入
- 每个 Store 实现后需性能基准测试

## 1. 8 个目标 Store

### 1.1 ProgressStore
- 聚合: workflow + execution_event
- 查询: get_project_progress(), get_chapter_workflow_status(), get_recent_events(), get_active_runs()

### 1.2 DraftStore
- 聚合: chapter + draft + instruction
- 查询: get_chapter_with_drafts(), get_latest_draft(), get_draft_history(), get_chapter_full_context()

### 1.3 WorldStore
- 聚合: story_fact + plot_hole + memory
- 查询: get_world_state(), get_active_plot_holes(), get_facts_by_type(), get_recent_memories()

### 1.4 SummaryStore
- 聚合: review + quality
- 查询: get_chapter_quality_summary(), get_review_history(), get_project_quality_trend()

### 1.5 CharacterStore
- 聚合: character + style_sample
- 查询: get_characters_with_samples(), get_character_arc()

### 1.6 OutlineStore
- 聚合: outline + instruction
- 查询: get_arc_outline(), get_chapter_instructions(), get_outline_progress()

### 1.7 SignalStore
- 聚合: genesis + project + queue + serial + batch
- 查询: get_project_signal(), get_queue_depth(), get_batch_progress()

### 1.8 CheckpointStore
- 聚合: chapter_versions + state_history
- 查询: get_chapter_checkpoint(), get_checkpoint_history(), get_latest_state()

## 2. BaseStore 接口

```python
# novel_factory/stores/base.py (proposed)

class BaseStore:
    def __init__(self, db: Connection | Repository):
        self._db = db
        self._repos: dict[type, object] = {}

    def _get_repo(self, repo_class: type[T]) -> T:
        if repo_class not in self._repos:
            self._repos[repo_class] = repo_class(self._db)
        return self._repos[repo_class]
```
