# 网文爽感写作规范

## 核心原则

爽文的本质是"情绪过山车"——持续制造低谷→蓄力→爆发的循环。
读者追更的动力来自"爽感期待"，即读者相信接下来会更爽。

## 钩子密度

- 每 500 字至少一个微型钩子（疑问、威胁、反转、新信息）
- 每章结尾必须有悬念钩子（未解决的冲突、新信息揭露、角色做出决定）
- 付费章前 3 章必须累积足够悬念，让读者"不得不充钱"

### 钩子类型

1. **悬念钩子**：抛出问题但不回答（"他到底是谁？"）
2. **威胁钩子**：危险逼近但未解决（"三秒后，门被踹开"）
3. **反转钩子**：预期被打破（"所有人都以为他输了，但他笑了"）
4. **信息钩子**：揭露部分真相，留下更大谜团
5. **选择钩子**：角色面临两难抉择，结果未揭晓

## 节奏曲线

- 压抑-爆发比例：3:7（压抑不超过 30%）
- 连续平淡不超过 2 段（每段约 300 字）
- 高潮场景后必须有短暂喘息（读者情绪重置）
- 每章至少一个小高潮或情绪爆发点

### 节奏模板

```
开场（钩子）→ 铺垫（200字）→ 冲突升级 → 小高潮 → 喘息（100字）→ 更大冲突 → 章末钩子
```

## 爽点类型

### 1. 打脸爽
反派轻视 → 主角展现实力 → 围观震惊
- 关键：反派必须先嚣张，围观者必须先嘲笑
- 打脸后要有"不可能！"的反应

### 2. 升级爽
突破瓶颈 → 获得新能力 → 立即验证
- 关键：瓶颈要有足够铺垫（至少 2 章的压抑）
- 突破后立刻展示新能力的威力

### 3. 捡漏爽
别人看不上 → 主角获得 → 后来证明价值连城
- 关键：要有"识货"的对比（别人不识货，主角识货）
- 价值揭露要有戏剧性

### 4. 装逼爽
低调出场 → 逐步展露 → 全场震撼
- 关键：低调要有原因（不想暴露、被小看）
- 展露要循序渐进，每一层都让观众更震惊

### 5. 打赌爽
对手挑衅 → 主角接受 → 碾压获胜
- 关键：赌注要够大，对手要有底气
- 获胜要干净利落

## 付费点设计

- 付费墙前 3 章：密集埋钩子，累积悬念
- 付费墙第 1 章：必须是大爽点或大反转
- 章末最后 100 字：必须留下"不看下一章会死"的悬念

### 付费章节奏

```
付费前3章: 钩子1 → 钩子2 → 钩子3（累积）
付费第1章: 大爽点 + 新钩子
付费第2章: 延伸爽点 + 更大悬念
```

## 禁忌

- 主角连续吃瘪超过 1 章（读者会弃书）
- 连续 3 个场景没有冲突（节奏太慢）
- 解决问题太容易（没有代价感）
- 反派智商突然下线（降低爽感价值）
- 主角全靠外力/运气获胜（削弱主角魅力）
- 爽点后没有"余韵"（爽完就结束，没有围观反应）

## 角色与爽感

### 主角要求
- 必须有明确的能力成长线
- 每次爽点后要有一个"新目标"或"新威胁"
- 性格要有"爽感基因"：不服输、有底线、关键时刻果断

### 反派要求
- 必须有嚣张的资本（实力、地位、人数优势）
- 嚣张程度要和最终打脸程度成正比
- 不同层级反派要逐步升级

## 章节结构模板

### 标准爽文章
```
1. 开局钩子（前100字抓住读者）
2. 铺垫/回忆（不超过200字）
3. 冲突发生
4. 主角应对
5. 小高潮
6. 短暂喘息
7. 更大冲突或反转
8. 章末钩子
```

### 过渡章
```
1. 上章余韵（50字）
2. 新信息/新目标
3. 准备/谋划（不超过300字）
4. 小冲突或发现
5. 章末钩子（指向下一章的大事件）
```
