# 角色塑造指南

## 核心原则

好角色的本质是"矛盾体"——外在表现与内在需求之间存在张力。
读者记住的不是角色的名字，而是角色的选择和代价。

## 主角魅力基因

### 必备要素
- **明确的能力线**：读者能清晰感知主角在变强
- **性格锚点**：用 3 个词概括主角性格（如"不服输、重情义、关键时刻果断"）
- **内在驱动力**：主角追求什么？为什么必须追求？（不只是"变强"，而是"变强是为了保护谁"）
- **弱点/代价**：完美主角没有魅力，弱点让读者共情

### 主角类型
1. **天才型**：起点高，但有更大的敌人等着（如：叶知秋）
2. **逆袭型**：起点低，靠毅力和机缘翻盘（如：林默）
3. **谋略型**：武力不高，但智商碾压（如：苏晚）
4. **热血型**：冲动但有底线，容易惹事也容易解决事

### 避免
- 主角全靠外力/运气获胜（削弱主角魅力）
- 主角性格前后不一致（除非有明确的成长弧线）
- 主角没有代价感（每次胜利都太轻松）

## 反派设计

### 层次原则
- **小反派**：1-3 章解决，给主角练手
- **中反派**：5-10 章解决，有明确的势力和动机
- **大反派**：贯穿全书，与主角有根本性冲突

### 反派魅力
- **有嚣张的资本**：实力、地位、人数优势
- **有合理的动机**：不是纯粹的坏，而是立场不同
- **嚣张程度与打脸程度成正比**：越嚣张，被打脸时越爽

### 反派智商
- 反派不能突然下线（降低爽感价值）
- 反派要有"识破主角计划"的能力
- 最终失败应该是"棋差一招"，不是"智商归零"

## 配角设计

### 功能化避免
- 配角不能只是"工具人"（出现就是为了帮主角/害主角）
- 配角要有自己的目标和动机
- 配角的"牺牲"要有意义，不能白死

### 配角类型
1. **伙伴型**：与主角互补，有自己的成长线
2. **导师型**：给主角指引，但不能帮主角解决所有问题
3. **对手型**：与主角竞争但不是敌人，推动主角成长
4. **信息型**：提供关键信息，但不能每次都是同一个人

## 角色口吻

### 区分原则
- 每个角色的说话方式要有辨识度
- 老者不能都"呵呵"，年轻人不能都"切"
- 角色的情绪变化要通过语言体现

### 口吻特征
- **身份**：决定用词（将军说"本将"，书生说"在下"）
- **性格**：决定语气（急躁的人话短，沉稳的人话多但有条理）
- **情绪**：决定语调（愤怒时短句，悲伤时长句）
- **关系**：决定称呼（对敌人用"你"，对朋友用"你"也可能用"兄弟"）

## 成长弧线

### 弧线结构
```
起点（缺陷）→ 触发事件 → 挣扎/尝试 → 第一次改变 → 更大挑战
→ 真正的成长 → 代价 → 新的自我
```

### 关键要素
- 成长必须有代价（失去什么才能得到什么）
- 成长不是线性的（可以有倒退，但最终方向是向前）
- 成长要体现在行动上（不只是内心独白）

## 禁忌

- 角色突然变强没有铺垫
- 角色行为动机不明（"因为剧情需要"）
- 配角出场即死，没有存在感
- 反派智商突然下线
- 角色口吻前后不一致
- 角色成长靠"顿悟"而非"经历"
