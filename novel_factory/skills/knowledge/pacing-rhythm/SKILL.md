# 节奏与张力指南

## 核心原则

节奏是"读者阅读时的心理时间流速"——不是实际字数，而是读者感受到的快慢。
张力是"读者对接下来会发生什么的期待程度"——越高越不想停下来。

## 章节节奏模板

### 标准爽文章（3000-4000字）
```
开局钩子（100字）→ 铺垫（200字）→ 冲突升级（800字）
→ 小高潮（500字）→ 喘息（200字）→ 更大冲突（800字）
→ 章末钩子（100字）
```

### 高潮章（4000-5000字）
```
直接进入冲突（无铺垫）→ 连续高潮（2000字）
→ 短暂喘息（300字）→ 最终爆发（1500字）→ 余韵+钩子（200字）
```

### 过渡章（2000-3000字）
```
上章余韵（50字）→ 新信息/新目标（500字）
→ 准备/谋划（800字）→ 小冲突或发现（500字）
→ 章末钩子（100字）
```

## 张力曲线

### 基本形状
```
张力
 ↑
 │      ╱╲
 │    ╱    ╲    ╱╲
 │  ╱        ╲╱    ╲
 │╱                  ╲───
 └──────────────────────→ 章节进程
```

### 张力要素
- **悬念**：读者想知道"会怎样"
- **威胁**：读者担心"会出事"
- **选择**：读者好奇"会选哪个"
- **反转**：读者惊讶"居然这样"

### 张力管理
- 张力不能一直高（读者会疲劳）
- 张力不能一直低（读者会弃书）
- 高潮后必须有喘息（情绪重置）
- 喘息后必须有新的张力（不能松到底）

## 信息释放节奏

### 原则
- 一次只揭露一个关键信息
- 信息之间要有间隔（不能一口气全说）
- 旧信息的解答要引出新问题

### 节奏控制
```
信息1（解答）→ 间隔（2-3章）→ 信息2（解答）→ 引出新悬念
→ 间隔（5-8章）→ 信息3（大揭秘）→ 更大的悬念
```

### 避免
- 一章内解答所有悬念（读者没有追读动力）
- 悬念拖太久不解答（读者会忘记或失去耐心）
- 解答太简单（"因为他是天选之人"）

## 场景切换

### 切换时机
- 高潮前切换（增加悬念：切到另一边看威胁在逼近）
- 信息揭露后切换（让读者消化）
- 选择前切换（增加紧张感）

### 切换技巧
1. **平行剪辑**：两条线同时推进，交替展示
2. **时间跳跃**：跳过不重要的时间，直接到关键时刻
3. **视角切换**：从主角视角切到反派视角，展示威胁

### 避免
- 在高潮中间切换（打断读者情绪）
- 切换后忘记回到原来的线
- 切换太频繁（读者会晕）

## 读者情绪管理

### 情绪周期
```
期待 → 紧张 → 释放 → 满足 → 新期待
```

### 情绪类型
- **紧张**：危险逼近、时间紧迫
- **兴奋**：突破、打脸、捡漏
- **感动**：牺牲、重逢、承诺
- **好奇**：悬念、谜团、新信息
- **满足**：问题解决、坏人受罚

### 情绪搭配
- 紧张后接兴奋（打脸爽）
- 紧张后接感动（牺牲/重逢）
- 兴奋后接紧张（爽完又有新威胁）
- 避免连续同类型情绪（读者会疲劳）

## 节奏加速与减速

### 加速技巧（快节奏）
- 短句为主
- 减少心理描写
- 动作连续，不打断
- 对话简洁有力

### 减速技巧（慢节奏）
- 长句为主
- 增加环境/心理描写
- 细节展开
- 对话深入（回忆、感慨）

### 切换原则
- 从快到慢：高潮后喘息
- 从慢到快：冲突爆发
- 渐变优于突变（除非是刻意的冲击效果）

## 禁忌

- 连续 3 章以上没有高潮（节奏太慢）
- 高潮后没有喘息（读者疲劳）
- 过渡章太长（超过 2 章纯过渡）
- 信息一口气全揭露（没有追读动力）
- 场景切换太频繁（超过 3 次/章）
- 张力曲线平直（没有起伏）
- 在高潮中间切换视角（打断情绪）
