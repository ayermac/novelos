# 对白自然度规范

## 核心原则

对白的功能是"推动剧情+揭示角色"，不是"传递信息"。
好的对白是"说一半藏一半"，让读者自己去理解潜台词。

## 对白功能性避免

### 什么是功能化对白
功能化对白是为了传递信息而存在的对话，角色像是在"念说明书"。

### 错误示例
```
"你知道吗？这座城已经存在了三百年，城主是天级强者，手下有十二个地级护卫。"
```
问题：没有人会这样说话。这是作者在借角色之口灌输设定。

### 正确示例
```
"三百年了。"老者看着城墙上的裂痕，"我还记得它刚建成的样子。"
"那时候城主还是个孩子。"他顿了顿，"谁能想到呢。"
```
同样是传递信息，但通过角色的回忆和感慨自然流出。

## 潜台词设计

### 原则
- 角色说的话 ≠ 角色想表达的
- 读者能从对话中读出"言外之意"
- 冲突往往来自"说的"和"做的"不一致

### 技巧
1. **欲言又止**：角色说到一半停住，让读者猜
2. **答非所问**：角色回避问题，暗示有隐情
3. **反话**：角色嘴上说不在乎，行动却暴露在乎
4. **沉默**：不回答本身就是一种回答

### 示例
```
"你恨他吗？"
她沉默了很久，最后说："茶凉了。"
```
没说恨不恨，但读者全懂了。

## 信息传递效率

### 原则
- 一段对话至少承担两个功能（推进剧情 + 揭示角色/关系/背景）
- 避免"废话对白"（删掉也不影响剧情的对话）
- 对白长度控制在 3-5 句以内（除非是重要独白）

### 信息密度
- **高密度对话**：每句都有信息量（紧张、冲突场景）
- **低密度对话**：轻松、过渡场景（但要有人物关系展示）

## 对白节奏

### 长短交替
- 紧张场景：短句为主（"跑！""不行！""快！"）
- 舒缓场景：长句为主（回忆、感慨、谋划）
- 避免连续 10 句以上都是短句或长句

### 打断与回应
- 角色可以被打断（增加紧张感）
- 角色可以不回应（增加悬念）
- 角色可以重复对方的话（强调或质疑）

## 角色口吻一致性

### 检查清单
- [ ] 每个角色的说话方式是否有辨识度？
- [ ] 老者和年轻人的用词是否不同？
- [ ] 角色在不同情绪下的语言是否有变化？
- [ ] 角色的口头禅/习惯用语是否一致？

### 常见错误
- 所有角色说话风格一样
- 角色突然改变说话方式（没有铺垫）
- 古代背景用现代网络用语（除非是穿越题材）

## 对白标签

### 原则
- "说"字够用就不要用"道""言""曰"
- 避免过度使用修饰词（"冷冷地说""淡淡地笑道"）
- 动作描写可以替代对白标签

### 示例
```
# 不好的
"你来了。"他冷冷地淡淡地说道。

# 好的
"你来了。"他没有抬头，手中的茶杯微微晃动。
```

## 禁忌

- 对白纯粹为了灌输设定（功能化）
- 所有角色说话风格一样（无辨识度）
- 对白过长（超过 5 句没有动作/心理穿插）
- 对白中角色突然变话痨（情绪不一致）
- 对白标签过度修饰（"冷冷地淡淡地笑道说"）
- 对白中角色说出自己不应该知道的信息
